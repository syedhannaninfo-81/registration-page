# 📝 Event Registration Portal( 1st development project )

A modern, responsive event registration web application built with **React** and **Tailwind CSS**.

🔗 **Live Demo:** [registration-page-green.vercel.app](https://registration-page-green.vercel.app)

---

## ✨ Features

* **Modular Architecture:** Component-based structure for event details, forms, header, and footer.
* **Responsive UI:** Fully responsive design styled with Tailwind CSS utility classes.
* **Client-Side Validation:** Interactive form handling and input validation.
* **Fast & Optimized:** Lightweight production bundle deployed on Vercel.

---

## 🛠️ Tech Stack

* **Framework:** React.js
* **Styling:** Tailwind CSS, PostCSS
* **Deployment:** Vercel
